### Upgrading Arches

1. Upgrade to at least version 8.1.0 before proceeding by following the upgrade process in the [Version 8.1.0 release notes](https://github.com/archesproject/arches/blob/dev/8.1.x/releases/8.1.0.md)

1. Upgrade to Arches 8.1.6

    ```bash
    pip install --upgrade arches==8.1.6
    ```

### Upgrading an Arches project

1. Rebuild your frontend bundle:

    - This version resolves security vulnerabilities in several frontend depenencies. For this reason, you'll want to be sure that the `arches-dev-dependencies` in your project's package.json file points to either the `dev/8.1.x` or `stable/8.1.5` branch.

        ```json
        "devDependencies": {
            "arches-dev-dependencies": "archesproject/arches-dev-dependencies#stable/8.1.6"
        },
        ```

    - Once you have confirmed your version of `arches-dev-dependencies`, you'll need to reinstall your frontend dependencies. To do so, run:

        ```bash
        rm -r node_modules; rm package-lock.json
        npm install
        ```

    - If you plan on doing active development, and need to see frontend changes automatically, run:

        ```bash
        npm start
        ```

    - If you do not plan to do active development, run:

        ```bash
        npm run build_development
        ```

    - if you are running in production, collect your static files:

        ```bash
        python manage.py collectstatic
        ```

1. If you are running Arches on Apache, restart your server:

    ```bash
    sudo service apache2 reload
    ```
