# Arches 7.6.25 Release Notes

## Bug Fixes

- Add validation for docx uploads [#12834](https://github.com/archesproject/arches/pull/12834)
- Change project template license to AGPL to be consistent with Arches [#12772](https://github.com/archesproject/arches/pull/12772)
- Tabbed reports accessibility - tab icons require tooltips and aria-expanded [#12833](https://github.com/archesproject/arches/pull/12833)
- Enforce resource instance permissions in edit log [#12836](https://github.com/archesproject/arches/pull/12836)

## Dependency changes

```yaml
Python:
    Upgraded:
        None
JavaScript:
    Upgraded:
        js-cookie: "2.1.1" -> "3.0.8"
        vitest: "^1.5.0" -> "^3.2.6"
```

1. Upgrade to version 7.6.0 before proceeding by following the upgrade process in the [Version 7.6.0 release notes](https://github.com/archesproject/arches/blob/dev/7.6.x/releases/7.6.0.md)

1. Upgrade to Arches 7.6.25

    ```bash
    pip install --upgrade arches==7.6.25
    ```

1. Rebuild your frontend bundle:

    - This version resolves security vulnerabilities in js-cookie and vitest. For this reason, you'll want to be sure that the `arches-dev-dependencies` in your project's package.json file points to either the `dev/7.6.x` or `stable/7.6.25` branch.

        ```json
        "devDependencies": {
            "arches-dev-dependencies": "archesproject/arches-dev-dependencies#stable/7.6.25"
        },
        ```

    - Once you have confirmed your version of `arches-dev-dependencies`, you'll need to reinstall your frontend dependencies to ensure `copy-webpack-plugin` and it's dependencies are removed. To do so, run:

        ```bash
        rm -r node_modules; rm package-lock.json
        npm install
        ```

    - If you plan on doing active development, and need to see frontend changes automatically, run:

        ```bash
        npm start
        ```

    - If you do not plan to do active development, run:

        ```bash
        npm run build_development
        ```

    - if you are running in production, collect your static files:

        ```bash
        python manage.py collectstatic
        ```

1. If you are running Arches on Apache, restart your server:

    ```bash
    sudo service apache2 reload
    ```
