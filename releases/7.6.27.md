# Arches 7.6.27 Release Notes

## Bug Fixes and Enhancements
- Notifications panel content is cut off and cannot be scrolled [#12953](https://github.com/archesproject/arches/pull/12953)
- Strengthen authorization checks on several endpoints
- Fix SelectWoo dropdown searching performance issues [#12967](https://github.com/archesproject/arches/pull/12967)

## Dependency changes

```yaml
Python:
    Upgraded:
        None
JavaScript:
    Upgraded via arches-dev-dependencies:
        "@vitejs/plugin-vue": "^5.0.4" -> "^6.0.10"
        "@vitest/coverage-v8": "^3.2.6" -> "^4.1.12"
        "typescript": "5.4.5" -> "^5.6.3"
        "vitest": "^3.2.6" -> "^4.1.12"
```

1. Upgrade to version 7.6.0 before proceeding by following the upgrade process in the [Version 7.6.0 release notes](https://github.com/archesproject/arches/blob/dev/7.6.x/releases/7.6.0.md)

1. Upgrade to Arches 7.6.27

    ```bash
    pip install --upgrade arches==7.6.27
    ```


1. Rebuild your frontend bundle:

    - This version resolves security vulnerabilities in vitest. For this reason, you'll want to be sure that the `arches-dev-dependencies` in your project's package.json file points to either the `dev/7.6.x` or `stable/7.6.27` branch.

        ```json
        "devDependencies": {
            "arches-dev-dependencies": "archesproject/arches-dev-dependencies#stable/7.6.27"
        },
        ```

    - Once you have updated your version of `arches-dev-dependencies`, you'll need to reinstall your frontend dependencies:

        ```bash
        rm -r node_modules; rm package-lock.json
        npm install
        ```

    - Next replace lines 5-10 in your project's vitest.config.mts file with these lines:

        ```js
        import { defineConfig } from 'vitest/config';

        import type { ViteUserConfig } from 'vitest/config';


        function generateConfig(): Promise<ViteUserConfig> {
        ```

    - If you plan on doing active development, and need to see frontend changes automatically, run:

        ```bash
        npm start
        ```

    - If you do not plan to do active development, run:

        ```bash
        npm run build_development
        ```

    - if you are running in production, collect your static files:

        ```bash
        python manage.py collectstatic
        ```

1. If you are running Arches on Apache, restart your server:

    ```bash
    sudo service apache2 reload
    ```
