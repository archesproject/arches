# Arches 7.6.26 Release Notes

## Bug Fixes
- Handle missing linked tiles for node-value nodes during csv search export [#12897](https://github.com/archesproject/arches/pull/12897)

## Dependency changes

```yaml
Python:
    Upgraded:
        None
JavaScript:
    Upgraded:
        None
```

1. Upgrade to version 7.6.0 before proceeding by following the upgrade process in the [Version 7.6.0 release notes](https://github.com/archesproject/arches/blob/dev/7.6.x/releases/7.6.0.md)

1. Upgrade to Arches 7.6.26

    ```bash
    pip install --upgrade arches==7.6.26
    ```

1. If you are running Arches on Apache, restart your server:

    ```bash
    sudo service apache2 reload
    ```
