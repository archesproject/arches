# Arches 8.1.3 Release Notes

## Bug Fixes

- Make cards with read or write perms available in reports [#12718](https://github.com/archesproject/arches/issues/12718)
- Fix the issue with ArcGIS Pro Addin failing to create a new resource by updating the nodevalue api and conversion from Esri json to geojson [#12704](https://github.com/archesproject/arches/issues/12704)
- Prevent file-widget viewmodel from submitting duplicate files on save [#12844](https://github.com/archesproject/arches/pull/12844)
- Add a guard against a missing properties key to getDrawFeatures in the map editor for single point geometries to prevent widget errors [#12810](https://github.com/archesproject/arches/issues/12810)
- Don't remove map advanced styling config in graph copy [#12847](https://github.com/archesproject/arches/issues/12810)
- Include url_subpath in Bulk Export download URLs [#12837](https://github.com/archesproject/arches/issues/12837)
- Fix webpack build issues affecting modern Vue `<script setup lang="ts">` syntax: restore `defineProps<T>()` type resolution, restore dev cache invalidation on project structure changes, enable hot module replacement, and prevent production minification from breaking runtime `constructor.name` checks [#12830](https://github.com/archesproject/arches/issues/12830)
- Add a guard against a missing `legacyid` when importing resources [#12665](https://github.com/archesproject/arches/issues/12665)

### Upgrading Arches

1. Upgrade to at least version 8.1.0 before proceeding by following the upgrade process in the [Version 8.1.0 release notes](https://github.com/archesproject/arches/blob/dev/8.1.x/releases/8.1.0.md)

1. Upgrade to Arches 8.1.3

    ```bash
    pip install --upgrade arches==8.1.3
    ```

### Upgrading an Arches project

1. Apply automatic updates:

    ```bash
    python manage.py updateproject
    ```

1. Rebuild your frontend bundle:

    - If you plan on doing active development, and need to see frontend changes automatically, run:

        ```bash
        npm start
        ```

    - If you do not plan to do active development, run:

        ```bash
        npm run build_development
        ```

    - if you are running in production, collect your static files:

        ```bash
        python manage.py collectstatic
        ```

1. If you are running Arches on Apache, restart your server:

    ```bash
    sudo service apache2 reload
    ```
